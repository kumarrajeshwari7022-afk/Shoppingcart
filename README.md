# Online E-Commerce Shopping Platform

## Project Overview

This is a full-stack e-commerce web application developed using Python and Django as part of my Python Full Stack Internship.

The application allows users to browse products, search products, add products to cart and wishlist, checkout, make payments, and view their orders.

## Features

- User Registration and Login
- Product Categories
- Product Search and Filtering
- Product Details
- Shopping Cart
- Wishlist
- Checkout
- Order Management
- Razorpay Payment Integration
- Admin Dashboard
- Product Management
- REST APIs

## Technologies Used

- Python
- Django 4.2
- Django REST Framework
- MySQL
- HTML5
- CSS3
- Bootstrap 5
- JavaScript
- Razorpay
- Git
- GitHub

## Database

MySQL is used as the database.

Main models:

- Category
- Product
- Order
- OrderItem
- Wishlist
